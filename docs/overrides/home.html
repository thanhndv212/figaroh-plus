Robot calibration · Dynamic identification · Experiment design

Turn your URDF and sensor logs into a model you can trust.

FIGAROH fits joint offsets, frame transforms, masses, inertias and friction from your measurements, plans the experiments that make them identifiable, and gives every result a pass/fail verdict.

Get started in 5 minutes → Use with an AI agent 
$ git clone https://github.com/thanhndv212/figaroh-examples
$ cd figaroh-examples/examples/ur10
$ python calibration.py --calibrate-only --no-plot
from figaroh.tools.robot import load_robot
from examples.ur10.utils.ur10_tools import UR10Calibration

robot = load_robot("urdf/ur10_robot.urdf", load_by_urdf=True)
cal = UR10Calibration(robot, "config/ur10_unified_config.yaml")
cal.initialize()
cal.solve(html_report=True)
print(cal.verify(scope="execution").passed)
→ HTML report→ verification JSON→ updated URDF

What do you want to do?

Pick a goal. You get what you need, what you get back, and the command that runs it.

You'll need

  • A URDF of your robot
  • Measured marker poses (mocap, laser tracker) with joint positions, as CSV
  • A YAML config that extends a robot template

You'll get

  • Identified offsets and transforms, with uncertainty for prior-based methods
  • An updated URDF
  • HTML report and a pass/fail verdict

Run it

cd figaroh-examples/examples/ur10
python calibration.py --calibrate-only --no-plot

One workflow, five steps

Calibration and identification follow the same path. Each step explains the choices you make and how you know it worked.

  1. 01PlanState the goal, list your data, choose what to estimate.
  2. 02DesignGenerate postures or trajectories that excite the parameters.
  3. 03ConfigureWrite a YAML config that extends a shared template.
  4. 04FitRun the solver. Read conditioning and residuals.
  5. 05VerifyCheck held-out data. Get a report and a verdict.
