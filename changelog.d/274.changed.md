Changelog entries are fragment files in `changelog.d/`, collected at release
with `towncrier build` (`towncrier` is in the `dev` extra), instead of edits to
`CHANGELOG.md` `[Unreleased]`, which every open pull request conflicted on
(#274, plan item Q3.4). The pending entries moved there unchanged.
CONTRIBUTING now asks for a branch to be synced with `devel` only when it
conflicts or CI needs a change, by rebasing it rather than merging `devel` in.
Contributor workflow only.
